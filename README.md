# Local Whisper Subtitles

Local Whisper Subtitles 是一款面向 Adobe After Effects 和 Premiere Pro 的本地字幕与文字图层插件。

插件支持 After Effects 2020（17.x）和 Premiere Pro 2020（14.x）及以后版本。语音识别、字幕生成和效果复制均在用户自己的电脑上完成，音频和视频不会因为使用插件而自动上传到云端。

## 主要功能

### After Effects

- 独立的文字图层效果复制工具。
- 按用户点击顺序记录效果来源层和应用目标层。
- 仅处理文字图层，可从当前合成或外部 AEP 合成选择来源。
- 支持复制文字图层属性、效果和关键帧。
- 来源层与目标层时长不一致时，关键帧时间按有效时长等比例映射。
- 效果复制可以脱离 STT 单独使用。
- 可选本地 Whisper STT，将选中音频或视频图层逐层转换为字幕文字图层。
- 可选 UVR5 人声提取，在 Whisper 识别前清理背景音乐和伴奏。
- 支持字体、字号、中心位置、字距、行距和每行字数上限等字幕参数。
- 支持原文、单语翻译和双语字幕。
- 可选 LLM 语义纠错及独立的“补全缺失内容”选项，改动文字可自选颜色，默认蓝色。
- 独立合成复制：提供一个包含文字和全部服务层的合成模板，按来源文字图层顺序分批复制完整合成并替换文字。预合成、表达式引用、遮罩、粒子和其他效果随副本保留；明确使用文字长度的 Index 文字选择器会按新文字长度调整。

### Premiere Pro

- 支持对活动序列 In/Out 范围内的混合音频进行本地 STT。
- 序列范围内没有有效音频波形时会自动跳过。
- 只生成简单字幕，不使用 MOGRT 或 AE 效果复制。
- Premiere Pro 23.0+ 自动建立原生字幕轨；Premiere Pro 2020–2022 会生成并导入 SRT 字幕素材，用户再将其拖入时间轴。
- 支持句子级断句、语音起止时间和双语字幕。
- Premiere Pro 不提供 AE 效果复制功能。

## 安装方式

安装器提供两种模式：

- **快速安装**：从零开始安装插件。可选择 After Effects、Premiere Pro，按需启用 STT 和 Vulkan GPU+CPU 加速；确认后下载安装器推荐的 Whisper 模型。
- **自定义安装**：只接入用户已有的模型和运行环境。不会下载模型，也不会安装 CPU/Vulkan runtime 或第三方运行时。使用 Premiere Pro 时，需要用户自行准备可用的 Whisper 模型和运行环境。

安装完成后，重新启动 Adobe 应用，并从“窗口 > 扩展（旧版）”打开插件面板。

## 使用方法

### AE 效果复制

1. 打开 AE 效果复制工具。
2. 点击“记录效果来源层”。
3. 依次点击需要作为来源的文字图层，再次点击按钮结束记录。
4. 点击“记录应用目标层”，按需要的顺序依次选择目标文字图层，再次点击按钮结束记录。
5. 展开属性树，默认会选中可复制的属性和效果；可取消不需要的项目。
6. 点击“复制效果”执行复制。

多个来源层会按照记录顺序循环应用到目标层。复制过程中会保留目标文字内容、图层时间和未冲突的效果。

### AE/PR 字幕识别

1. 在 AE 中选择需要处理的一个或多个音频/视频图层；在 PR 中打开目标序列。
2. 设置识别范围。AE 按选中图层和合成范围处理，PR 使用活动序列 In/Out 范围的混合音频。
3. 选择本地 Whisper 模型和可用运行环境。
4. 根据需要启用 UVR5 人声清理、语言翻译和双语字幕。
5. 在 AE 中可设置字幕字体、字号、位置、字距、行距和每行字数上限；PR 字幕样式在 Premiere 的字幕工具中调整。
6. 点击字幕识别按钮开始处理。

AE 中每个选中的图层都会作为独立任务执行，并分别建立字幕结果；PR 将活动序列 In/Out 的混合音频作为一个任务。没有音频波形或没有有效语音的输入会被跳过。字幕时间取实际语音的起始和结束时间，自动断句与每行字数上限分别处理。

### LLM 语义纠错（可选）

在“语言输出”中开启“LLM 语义纠错”，配置大模型 API 地址、模型和 API Key。STT 原文、单语言和双语模式均可使用。该选项默认关闭，关闭时继续按原来的逐图层转写、翻译和写回流程运行。

开启后，所有选中图层先完成本地 STT，再把全部识别文本统一发送一次大模型请求；纠错和所选语言的翻译在同一响应中完成。各图层依然分别建立字幕，原始字幕起止时间保持不变。不会自动拆分请求或重试；请求失败、超时或结果格式不匹配时保留原始 STT 字幕，并显示提示。

提示词要求模型根据上下文修正错词，保留原有表达，不润色或改写整句话。“补全缺失内容”是另一个独立复选项，只有勾选后才允许补齐有上下文依据的缺漏；模型的判断仍需使用者核对。

纠正或新增的文字默认标蓝，可使用颜色选择器调整。AE 在模板效果和样式应用后为改动部分添加文字颜色动画器，其他文字继续使用模板颜色；支持逐句图层和单层文字关键帧模式。双语中对应的改动译文也会标色。PR 原生字幕的公开脚本接口不支持逐字颜色，因此正常生成字幕轨，并提供“查看纠错标色核对”文件用于核对。AE 也提供该文件，方便对照 STT 原文与最终文本。

识别文本会发送到用户指定的大模型接口；音视频不会随此请求上传。API Key 仅保存在当前会话内，开关、颜色、接口地址和模型名称会保存到配置中。

### AE 独立合成复制（整组效果）

1. 在 AE 中把一句字幕的完整样子搭建为一个独立合成：文字图层加上所有为它服务的层（粒子、花瓣、遮罩、调整层等）。
2. 在“合成复制”中记录来源文字图层；点击一次开始记录，按顺序选择图层，再次点击结束，可在列表中调整顺序。
3. 选择当前项目或外部 AEP 中的模板合成，点击“复制合成”。模板有 M 个文字层、来源有 N 个文字层时创建 `ceil(N/M)` 个完整副本，按顺序每 M 个替换一批，最后一批空余文字层保留模板内容。

复制会实例化模板引用的预合成，重绑定副本内指向模板合成的静态 `comp("...")` 表达式，并保留图层、关键帧、遮罩、父子关系和效果。文字源存在关键帧时只替换每个关键帧的文字并保留样式与时间；Source Text 表达式默认关闭执行以确保新文字可见，并在结果中提示。没有明确文字依赖的第三方固定参数不会被猜测性缩放。

## 模型和运行环境

插件可以使用以下任一类本地环境：

- whisper.cpp CPU runtime
- whisper.cpp Vulkan GPU+CPU runtime
- OpenAI Whisper、faster-whisper 或 Transformers Whisper 的 Python 环境
- CUDA/PyTorch GPU 环境，以及支持显存不足时 CPU+GPU 混合放置的环境

模型和运行环境由插件自动检测。自定义安装不会替用户下载或安装这些资源；如果资源缺失，插件会明确提示需要准备的项目。

## 注意事项

- 使用安装器或更新插件前，请先关闭 After Effects 和 Premiere Pro。
- AE 效果复制只接受文字图层来源和文字图层目标。
- Premiere Pro 只能使用字幕识别功能，不能使用 AE 效果复制功能。
- Premiere Pro 的字幕对象是字幕轨，不是 AE 式文本图层。PR 2020–2022 没有公开的自动创建字幕轨脚本接口，因此使用已导入的 SRT 素材完成最后放置。
- 翻译功能需要用户自行配置可用的大模型 API。
