# 决策记录

## DEC-002 独立合成复制工具（4.0.0）

- 日期：2026-09-12
- 状态：实现中，独立于字幕识别与 3.0.0 特效复制

### 行为

1. 用户点击一次开始记录来源文字图层，按点击顺序加入；再次点击结束。来源合成在记录时锁定，避免导入 AEP 或切换合成后引用错误。
2. 模板是完整合成，可来自当前项目或外部 AEP。模板内文字图层按顶层到预合成的显示顺序排列。
3. 来源 N 个、模板文字槽 M 个时创建 `ceil(N/M)` 个完整合成副本，按 `batch*M+slot` 顺序替换；最后一批没有来源的槽位保留模板文字。
4. 复制完整合成图并实例化预合成，保留图层、关键帧、遮罩、父子关系、拾取关系和效果。副本中静态 `comp("原合成名")` 引用会重绑到对应副本，注释和字符串字面量不改。
5. Source Text 关键帧只替换文字字段，保留每个关键帧时间和样式。启用 Source Text 表达式的副本关闭表达式执行并给出警告，保证新文字可见。
6. 文字选择器只有在 Index 单位时按新旧文字长度调整 Start/End，并限制到合法字符范围；Percentage 单位、固定路径和无法确认语义的第三方属性原样保留。

### 边界

任意第三方效果没有统一的“文字长度”语义，插件不会把所有数值、坐标或关键帧猜测性缩放。模板作者应使用表达式、拾取、遮罩或 Index 文字选择器明确建立文字依赖；这些依赖会随完整合成副本一起保留或重绑定。无法自动判断的效果在结果警告中报告。

### 兼容与隔离

旧 `ae.modules.copy` 路由、旧属性树、旧记录器和 v3.0.0 效果复制实现保持不变。新模块使用 ExtendScript ES3，并通过独立 `ae.comp.copy.*` 路由调用。Premiere 只保留字幕识别，不显示合成复制工具。
